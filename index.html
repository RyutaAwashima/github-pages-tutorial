GitHub Pages の使い方

1. GitHub アカウントを作ろう

GitHub を使うには、まずアカウントを作成する必要があります。公式サイト（https://github.com）から簡単に登録できます。

2. 新しいリポジトリを作成しよう

リポジトリとはプロジェクトの「フォルダ」のようなものです。新しいプロジェクトを始めるには、トップページ右上の「+」ボタンから新規作成できます。

3. GitHub Pages を有効化しよう

作成したリポジトリで「Settings」タブを開き、「Pages」のセクションに進んでください。有効にしたいブランチを選択するだけで、サイトを公開できます。

4. 公開されたサイトを確認しよう

GitHub Pages で公開されたサイトは、通常 "https://[your-username].github.io/[your-repository-name]" でアクセスできます。
