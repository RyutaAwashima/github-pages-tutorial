JavaScriptでできることの例

Webページに動きや便利な機能を追加できるのが JavaScript です。

1. ボタンを押してメッセージを表示する

JavaScript を使うと、ボタンをクリックしたときにメッセージを表示することができます。 これは、ユーザーの操作に反応する基本的な例です。

できること: クリックに反応して内容を変える

2. 数を自動で計算する

JavaScript は計算も得意です。例えば商品の合計金額、テストの点数、簡単なゲームのスコアなどをその場で計算できます。

例: 3 + 5 を計算して表示する

3. ページの見た目を変える

JavaScript では、ボタンを押したときに色を変えたり、文字を切り替えたりできます。これにより、動きのあるページを作れます。

できること: 背景色を変えてページに変化をつける

4. 入力内容をチェックする

フォームに何か入力してもらうとき、JavaScript を使えば「空欄では送信できない」などのチェックができます。 これを入力チェックといいます。

できること: 入力漏れを防ぐ
